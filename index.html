LLM Inference Deployment

Fine-tuned LLaMA 3.2-1B served locally through FastAPI in three configurations — base, LoRA, and merged — for biomedical use. 8-bit quantization brings GPU memory down to ~1.8 GB, and the whole pipeline ships as a GPU-enabled Docker container with a web UI for side-by-side model comparison.

  • Python
  • FastAPI
  • Docker
  • PyTorch
  • LoRA

2026

LLM Fine-tuning — BioInstruct

Parameter-efficient fine-tuning of LLaMA 3.2-1B-Instruct on a 15K-sample biomedical instruction dataset to evaluate domain adaptation. LoRA adapters merged into a standalone model and published on Hugging Face for downstream use.

  • Python
  • PyTorch
  • LoRA
  • Unsloth
  • Hugging Face
